# Copy Terminal Output

A small VS Code extension: highlight text in the integrated terminal, right click, and choose **Copy Output** to copy it to your clipboard.

## Usage
1. Highlight any output in the VS Code terminal.
2. Right click and choose **Copy Output**.
3. Paste anywhere.

## Install
Download the `.vsix` from the Releases page, then run:

```
code --install-extension copy-terminal-output-1.0.2.vsix
```

Or in VS Code: Extensions panel → `...` menu → **Install from VSIX...**

## Build from source
```
npm install -g @vscode/vsce
vsce package
```
